# code-notes

> My C++ algorithm learning — Luogu practice & contests

洛谷（Luogu）刷题与月赛代码存档，C++ 为主。

## 目录结构
- `practice/` — 平时练习。文件名即洛谷题号（如 `P1036`、`B2089`），颜色后缀区分多次提交（`ora`/`yel`/`gre`/`red`）
- `competition/` — 月赛 / 比赛。按日期分文件夹（如 `9.27`、`10.1`），每场 `T1`~`T5`
- `.cph/` — Competitive Programming Helper 本地测试用例（不纳入版本控制）

## 说明
- 编译产物（`.exe` / `.o`）已加入 `.gitignore`，不入库
- 题号对应洛谷题库，难度以洛谷官方评级为准
- 每题文件内含思路注释与复杂度说明
