- P5960【模板】差分约束（P5960 gre.cpp）诊断：
  - 题面：输入 c c' y 表示 x_c - x_{c'} ≤ y；输出一组解（空格分隔），无解输出 NO；n,m ≤ 5000，c≠c'，时限 1s，SPJ。
  - 错误1（核心）：建边方向反了。应为 c'→c 权 y（即 v→u，挂在 head[v]），代码建成了 u→v。实测样例输出 0 0 -2，代回 x2-x3=2 ≰ -2；只改方向后输出 0 -2 0，三条约束全过。30 组随机对拍：原版错 14 组，改方向后 0 组。
  - 错误2：edge[8010] 不够，需要 m+n = 10000；n=m=5000 满数据实测 SIGSEGV（退出码 139）。应开 10005+。
  - 注：结构体 fro 字段从未使用，真正的起点是 head[] 下标；改方向时只改 fro/to 不改 head[v] 会错（学长自己第一次 sed 就踩了）。
- 用户已改对建边方向（fro=v, to=u, nxt=head[v], head[v]=lin）。验收：样例输出 0 -2 0 三条约束全 OK；30 组随机对拍 0 错。
- 剩余唯一问题：edge[8010] 不够，n=m=5000 满数据 SIGSEGV（139）。本机实测改成 edge[20010] 后：满数据有解场景 5000 个解、0 条违反；5000 点大负环场景正确输出 NO，耗时约 0.4s（扣启动基线）。
